What it does

Offline help when you need it.

Choose the capabilities that match the available drive space and the computer you are using.

💬 Local AI chat

Ask questions using an on-device model. Chat stays local and works without a network connection.

📁 My Documents

Place supported files in My Documents on the USB. The kit recognizes and indexes them for grounded answers with citations.

🧠 Remember

Say “remember that…” to save useful information locally. You stay in control of what is saved and can review it later.

🖼️ Images

Image attachments use local OCR today. Optional vision models add richer local diagram, chart, and scene understanding on capable computers.

⚙️ Models & skills

Install, enable, disable, or switch supported components. The app shows storage and hardware compatibility before activation.

🔒 Private by design

No silent upload: local chat, documents, and memory remain on the selected drive unless you intentionally export them.

Tutorial

Get started in four steps.

01 — SET UP
Run the provisioner

Select a supported USB drive and a plan. The app checks free space before writing.

02 — START
Open the kit

Run AI-Survival-Kit.exe from the USB. It selects a compatible local runtime for that computer.

03 — ADD DOCUMENTS
Use My Documents

Save TXT, Markdown, CSV, JSON, LOG, and text-based PDF files in the USB’s My Documents folder.

04 — ASK
Choose your source

Turn on My Documents in chat when you want file-backed answers. Keep it off for Local AI only.

Ask about your files

When My Documents is on, Kit Bot looks for relevant passages and shows the file source. Files remain local; indexing only needs to repeat for new or changed files.

Use temporary attachments

Use the plus button beside the chat box for one-off files or images. The app asks whether to analyze the attachment or answer normally with local AI.

Choose a model or skill

Open Settings → Models & Skills to see what is installed, enabled, compatible, and active. Never remove a model unless you understand its storage impact.

Carry it safely

Copying and moving the kit.

The kit is portable. You can copy it to another suitable drive, provided the complete folder structure is preserved.

Do

  • Copy the complete AI-Survival-Kit folder.
  • Keep Models, Runtime, Data, Config, and My Documents together.
  • Use Windows “Safely Remove Hardware” before unplugging.
  • Keep a trusted backup of your kit and documents.

Don’t

  • Do not rename or move individual runtime/model files.
  • Do not unplug while a model, document, or update is being written.
  • Do not assume every computer has enough memory for every model.
  • Do not treat AI output as professional advice.

Hardware guidance

The app detects the current computer and suggests an appropriate profile. Larger models and advanced image understanding need more RAM and free drive space.

Important: Kit Bot can make mistakes. Review important information, especially medical, legal, financial, and safety-critical guidance.
Questions

Quick answers

Does it need the internet?After the kit, runtime, and model are installed, chat and document search run offline. Downloads and updates naturally require an internet connection.
Can I add my own files?Yes. Save supported documents in My Documents, then open the kit. It detects new files and lets you update the local library.
Can I change models later?Yes. Models & Skills lets you choose supported official model packages, view requirements, and activate compatible components.
