TUTORIAL · PORTABLE OFFLINE AI

Use your kit with confidence.

Set up your USB drive once, then use local AI, documents, memory, and optional skills without sending your work to a cloud service.

START HERE

Four simple steps.

01 · SET UP

Run the provisioner

Choose a writable compatible USB and select a kit. It checks free space before installation.

02 · OPEN

Start the kit

Run AI-Survival-Kit.exe directly from the USB. The app chooses a compatible runtime for the computer.

03 · ADD

Use My Documents

Save files in the drive’s My Documents folder. The kit finds new and changed supported files.

04 · ASK

Chat locally

Turn My Documents on in chat for file-backed answers, or leave it off for Local AI only.

USEFUL FEATURES

Make the kit your own.

My Documents

Add TXT, Markdown, CSV, JSON, LOG, and text-based PDF files. The app builds a local search library and shows source passages for file-backed answers.

Remember

Say “remember that…” followed by information you want saved. You can review and manage saved memory locally.

Temporary attachments

Use the plus button in chat for one-off files or images. The app asks whether you want the attachment analyzed.

Models & skills

Settings → Models & Skills shows installed, enabled, compatible, and active components—plus storage and hardware requirements.

Images

OCR can read text in images. Optional vision models add richer local understanding of diagrams, charts, objects, and scenes on capable hardware.

Safe portability

Copy the complete AI-Survival-Kit folder when moving the kit. Keep Models, Runtime, Data, Config, and My Documents together.

Important: Use Windows Safely Remove Hardware before unplugging. Kit Bot can make mistakes, so review important medical, legal, financial, and safety-critical information.
